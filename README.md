## Engineering Principles

- **Problem first:** Define the decision and user before selecting a model.
- **Reliable data:** Clean inputs, prevent leakage, and protect sensitive information.
- **Simple before complex:** Prefer the simplest method that performs the job well.
- **Honest evaluation:** Publish meaningful metrics where available and avoid unsupported claims.
- **End-to-end delivery:** Connect models to APIs and interfaces rather than stopping at notebooks.
- **Human control:** Treat sensitive predictions as decision support, not unquestionable truth.
- **Continuous improvement:** Add testing, calibration, monitoring, bias review, and feedback loops.
